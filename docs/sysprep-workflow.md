# Захват sysprep-образа

Утилита **не запускает sysprep**: он работает только в самой Windows. Она захватывает уже обобщённую систему из WinPE.

## Порядок

1. **В эталонной Windows** выполните `sysprep /generalize /oobe /shutdown` (при необходимости с `/unattend:<файл.xml>`). Удобно обернуть это в свой скрипт с проверками и очисткой.
2. После выключения **не загружайте Windows** — сразу загрузитесь в WinPE. Одна загрузка запустит OOBE и испортит обобщённое состояние.
3. Запустите `WinInstaller.exe` → вкладка **«Захват образа (sysprep)»**.
4. Выберите раздел с Windows. Утилита офлайн читает `HKLM\SYSTEM\Setup\Status\SysprepStatus\GeneralizationState`: значение **7** означает, что sysprep выполнен. Иначе будет предупреждение.
5. Укажите файл `.wim` (на **другом** разделе), имя, сжатие. XML — по желанию.
6. Утилита выполняет `dism /Capture-Image … /CheckIntegrity`, проверяет заголовок образа и (по желанию) пишет `<образ>.wim.sha256`.

## XML при захвате

Если путь к XML указан, файл на время захвата копируется в `Windows\Panther\Unattend\Unattend.xml` захватываемой системы и попадает в образ; после захвата раздел возвращается к прежнему состоянию. Если поле пустое — образ захватывается как есть.

## Что сохраняется и что обнуляется

| Сохраняется | Обнуляется sysprep-ом |
|---|---|
| Установленные программы, службы, драйверы | SID машины, имя компьютера |
| Политики (реестр, `GroupPolicy`) | Привязка к конкретному железу |
| Задачи планировщика | Состояние OOBE (запустится по вашему XML) |
| Файлы и ярлыки в существующих профилях, Public Desktop | Активация Windows |

## Типичные проблемы

- **Приложения Магазина.** Частая причина падения sysprep: приложение установлено для пользователя, но не провижинено. Удалите такие приложения; смотрите `Windows\System32\Sysprep\Panther\setuperr.log`.
- **CopyProfile.** Новые локальные учётные записи создаются из чистого Default-профиля. Хотите общие ярлыки — кладите их в Public Desktop или Default-профиль, либо настраивайте при первом входе.
- **Шифрование диска** перед sysprep нужно отключить.
- **Драйверы хранилища** (NVMe, RAID, Intel RST/VMD): если их нет в образе, развёрнутая система не загрузится на новом железе. Используйте опцию установки «Добавить драйверы из папки».
- Лицензии и всё, что привязано к имени, SID или железу, нужно переактивировать после развёртывания.
